BidirFlow

Catching fake trading in real time, in 32 MiB.

A streaming detector that flags wash trading, layering and circular trading rings on live Ethereum transfers, in constant memory at 213,000 transfers a second. It holds up on held-out and pre-registered windows (0.90, 0.94) and on Polygon (0.95). The sketch core is written in Verilog, verified bit for bit against the Python model, and placed and routed on a Lattice ECP5 FPGA at 77.6 MHz. A live dashboard answers plain-English questions through a local LLM (Ollama) that calls the detector’s tools.

  • 0.963avg precision vs 0.009
  • 213K/stransfers · 10,800× real time
  • 77.6 MHzon a Lattice ECP5 FPGA

RescueSched

When seconds matter, the scheduler decides.

A CPU-GPU inference scheduler for disaster imagery. A fine-tuned MobileNetV3 scores each image’s hazard severity and the queue is re-prioritised so the worst damage is analysed first. A random forest predicts runtimes, then a deadline-weighted cost picks CPU or GPU and a batch size from 1 to 64.

  • MobileNetV3hazard severity
  • 1–64adaptive batch size
  • CPU / GPUdeadline-weighted cost

A security operations centre ready for quantum attackers.

A quantum-aware Security Operations Center: a rule engine with 17 MITRE ATT&CK-tagged rules, an attack simulator, a Quantum Readiness Index, Qiskit Grover and Shor demos, and reports signed with post-quantum ML-DSA-65. Detection passed 220 of 220 runs across 11 scenarios plus a 33/33 negative control, and batching raised ingestion from 35 to 1,526 events a second.
